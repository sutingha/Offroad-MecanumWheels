Mecanum Wheels
=======

A NeoForge addon for Create: Aeronautics that adds 8 Mecanum wheels
for omnidirectional vehicle movement.

Features
-------

- 8 wheels: Small / Standard / Large / Monstrous × CW / CCW
- Omnidirectional movement: strafe, diagonal, turn-in-place
- In-game config via `/mecanum config`

Dependencies
-------

- NeoForge 1.21.1
- Create
- Create: Aeronautics
